Interactive Elements

Tactile interactions with sub-200ms latency.

All interactive elements—accordions, filter bars, lightboxes, and modals—respond with smooth cubic-bezier settling curves.

The header strictly contains Zone 1 (Wordmark), Zone 2 (4–6 text navigation items), and Zone 3 (Action controls). Subtitles, locations, and telemetry tickers are banned from cluttering the navigation bar.

  • Zone 1: Single element <a class="brand-wordmark">Atelier</a>
  • Zone 2: Subtle underline hover animation on active links
  • Zone 3: High-contrast Theme Toggle, Sign In, and Get Started CTA

Static informational labels (dates, counts, categories) are never enclosed in artificial pill badges or rounded capsules. They are presented as clean unboxed text separated by typographic middots (·) or forward slashes.

  • Eliminates visual candy clutter and generic AI styling
  • Ensures comfortable reading cadence for editorial publications
  • Strictly differentiates static metadata from interactive buttons

All visual photography slots include high-resolution references generated specifically for this template. Clicking any plate opens the accessible lightbox modal complete with plate metadata, ESC closing, and backdrop dismissal.

  • Aspect ratios tailored to architectural containers (16:9, 4:3, 1:1)
  • Accessible ARIA dialog roles and keyboard escape traps
  • Zero external third-party image host dependencies
